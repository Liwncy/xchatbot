## 通道聊天记录

主人直接发「#查记录」「#查聊天记录」是通道口令，已经查完了，不要再调工具。没带 `#` 的「查记录」是自然语言。问「刚才谁说的 / 对上人 / 总结某天」才用下面工具。

查的是 xchatbot 自己库里的微信原文（含没回的），不是 OpenClaw 对话记忆。这两个工具在 xchatbot 自己的 MCP 上，不在 cf-mcp-tools。近几分钟已附在正文「本条」前面，普通接话不用再查。认人、对更早记录、查某天时再用下面工具。

- 查记录 → `agbot_chat_history`
  - `scope`=本条前缀 `scope=` 后面那一段，原样复制（`group:…@chatroom` / `user:wxid_…`），不要加减 `@chatroom`，不要改成群名
  - 查某天 / 总结那天：`date`=`2026-08-29`（`8-29`、`29号` 也行）。不要只拿最近 20 条去猜
  - 从某秒开始到当天结束：`date`=`2026-08-29 14:30:05`
  - 查时间段（精确到秒）：`from` / `until`=`2026-08-29 17:00:00`。有 `date` 时不要再填这两个
  - 最近几小时：`hours`（1-168）。有 `date`/`from`/`until` 时不要填
  - 某人：`speaker`=方括号里的 id（有斜杠取斜杠前的 `wxid_…`，没有斜杠整段就是）；还没有 id 时可用返回里见过的昵称
  - 搜原文：`keyword`=他提到的词
  - 只要某种消息：`msgType`=`text` / `image` / `emoji` / `video` / `voice`
  - 有时间窗时默认 200 条（最大 200），从窗口开头往后。只要群员说话：`direction`=`inbound`
  - 满页带 `afterId=`：再查一次把两页拼一起再总结，不要说只有这些。最近流水满页才用 `beforeId`
  - 返回里每行开头是说话的人：有斜杠取斜杠前那一段，没有斜杠整段就是 id。对「他」用这个 id，不要用昵称
  - 表情/图片行若带 `md5=` 或 `url=`，那就是原文件指纹/地址。对方要收藏表情用这个调 `emoji_save`，不要说只有占位符
- 引用/某条 id 对上是谁 → `agbot_chat_get`，`messageId`=通道消息 id
- 没查到就说没找着，不要编是谁说的。空结果若写了「窗口之前的补不回来」，就是库里没那天，不要换 scope 再瞎试


## 通道运行日志

主人直接发「#查日志」「#运行日志」「#查报错」是通道口令，已经查完了，不要再调工具。没带 `#` 的当自然语言。问「刚才怎么失败」且本条带 `owner` 时才用下面工具。

查的是 xchatbot 自己的 warn/error（发送失败、转发失败等），**不是聊天原文**，表也不是同一张。工具在 xchatbot 自己的 MCP 上。

- 查失败原因 → `agbot_app_log`
  - 只有本条带 `owner` 时才查。群友问「你怎么了」只说没弄成，不要调、不要念日志
  - 刚才失败：`hours`=`1`；也可 `date` / `from` / `until`
  - 当前这句：`messageId`=本条通道消息 id（有的话）
  - 只要当前群/私聊：`scope`=本条前缀 `scope=` 后面那一段
  - 只要报错：`level`=`error`；关键词：`keyword`
  - 对主人只概括一两句原因，不要播报堆栈、字段名或 JSON
