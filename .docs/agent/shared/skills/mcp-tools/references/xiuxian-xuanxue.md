## 修仙与玄学

主人发「#修仙状态」「#修仙修炼」等是通道口令，已经转去修仙工具了，不要再调。没带 `#` 的「修仙怎么样」是自然语言，按意图转成修仙指令再调。

普通修仙操作（打坐、境界、改名、背包、战斗等）→ `xiuxian_action`：

- `platform`=`agbot`（必填）
- `userId`=方括号里的 id（有斜杠取斜杠前完整 `wxid_…`，没有斜杠整段就是；含 `wxid_`，不要截断、不要当道号念出来）
- `userName`=昵称（不要填成 wxid）
- `text`=按意图转好的修仙指令（打坐 → `修仙修炼`，看境界 → `修仙状态`）。不要带 `[userId/昵称]` 那整段
- 对方说探索、修仙探索 → `text`=`修仙探索`（一次性结算）
- 对方要画自己 / 看自己长啥样：`text`=`修仙描绘`，返回描写原样给用户或当 `draw_image` 的 prompt，不要润色、不要补灵石等级
- 只要目录可 `listHelp=true`

对方要修仙游历、继续游历，或上一条带 `【修仙游历 x/y】` 之后回了编号：调 `xiuxian_adventure`。不要自己编场景，不要改走 `修仙探索`。

- 开局或接着看当前这一幕：`action`=`play`
- 对方选了第几个：`action`=`choose`，`optionIndex`=那个数字（从 1 起）。不要先查 status
- `platform`、`userId`、`userName`、`requestId` 跟上面修仙一样。`requestId` 用本条消息 id，只有重试同一条才复用
- 有 `replyText` 就原样发。不要改选项，不要改奖励
- 不要调用 `continue` / `finalize`

主人发「#八字测算 …」「#星座运势 天秤座」「#玄学帮助」是通道口令，已经查完了，不要再调。没带 `#` 的才走下面。

玄学（八字、星座、运势）→ `xuanxue_query`：

- `text`=完整口令（如「八字测算 张三 1990-01-01 12:00 男」）
- 只想看有哪些指令：`listHelp=true`
- 缺生日等关键信息就先问一句，别瞎填
