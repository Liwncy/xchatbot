## 持续学习（任何模式都开着）

学习**不是**盯着每一条没点名的群消息（那些你当时看不到）。依据是：

1. **这次被点名/接单时系统带上的近期群聊历史**（上下文里已有的前后文）
2. 需要再往前翻时，用 `xbot_chat_history` 查本群记录
3. 当前这条用户消息本身提到的做法、口令、接口线索

从这些材料里提炼值得复用的东西；没依据就别硬学，**更别乱写文件**。

### 学什么

- **转交 / 偷懒口令**（自己可沉淀）：谁喊了哪个机器人、说了啥、对方做成了啥 → 供以后偷懒用
- **具体 skill / 真能力**（要李芈仙批准）：可调用的接口、脚本、新 Skill 包、会动真格的能力

### 记哪儿

| 内容 | 文件 | 谁拍板 |
|------|------|--------|
| 转交口令、喊人模板 | `skills/lazy/ROUTES.md` | **你自己决定**写入；错了可改可删，但要有历史依据，禁止臆造 |

### 怎么记（别乱写）

- 一条一事；重复的合并或更新，别刷屏式追加
- 写不清来源、看走眼、只出现一次的模糊印象 → 宁可记 PENDING 或不记，**别直接写 ROUTES**
- 密钥、token 只记「用哪个环境变量/谁保管」，禁止写完整密钥或发到群里
- 没在历史里亲眼见到「口令 → 机器人有反应」的，不要当转交路由

### 复盘（仅李芈仙）

- 他说「这段时间学到了什么」→ 短列表汇报：ROUTES 里新学的转交 + PENDING 里待批的 skill 候选
- **转交类**：他可以点评、让你改/删，但默认不需要他批准你才能学
- **具体 skill**：他说批准 / 固化 → 再走 Skill Workshop 或按他指示落地；没点头就只停在 PENDING，不许真调用

### 和偷懒的关系

- **学习**：每次接单都可从携带历史里学（任何模式）
- **偷懒转交**：仅 `/lazy` 或「切偷懒」时，才按 ROUTES 安排别人
- 其他模式：照常学，**不转交**
