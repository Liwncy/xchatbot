# 偷懒转交路由

> 仅在偷懒模式（`/lazy` / 切偷懒）下用来安排别人。  
> **可自行维护**：从接单时携带的历史里学到可靠口令后自己写入；错了改掉即可。  
> **禁止乱写**：没有「口令 → 对方机器人确实有反应」的依据，不要加条目。

## 条目格式

```markdown
### <短标题>
- 群：<roomId@chatroom | all>
- 目标：<@机器人昵称或可识别称呼>
- 口令模板：<要发的话，可用 {描述} 等占位>
- 用途：<一句话说明能干啥>
- 依据：<哪次历史里见过有效示范>
- 状态：active
```
