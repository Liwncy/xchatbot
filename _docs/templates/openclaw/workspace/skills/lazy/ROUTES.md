# 偷懒转交路由

> 仅在偷懒模式（`/lazy` / 切偷懒）下用来安排别人或套用指令。  
> **可自行维护**：接单时从历史里学到就写；错了改掉即可。  
> **放宽记**：指令口令、@机器人、@人且对方有回应、有人认真答了某类问题——有依据就可记。  
> **别空写**：群尽量真实 roomId；目标写具体人/机器人；禁止「(见口令模板)」。

## 条目格式

```markdown
### <短标题>
- 类型：command | bot | human
- 群：<roomId@chatroom | all | unknown>
- 目标：<昵称或 @称呼；指令型也尽量写会响应的人/机器人>
- 口令模板：<要发的话，可用 {描述} 占位；咨询人可用「@某某 {问题}」>
- 用途：<一句话说明能干啥 / 什么时候问 TA>
- 依据：<谁→谁，做了啥；勿臆造>
- 状态：active
```

类型说明：

- `command`：固定指令格式（如 `music {歌名}`），不一定带 @
- `bot`：喊某个机器人干活
- `human`：真人懂某块，以后可 @/问 TA
