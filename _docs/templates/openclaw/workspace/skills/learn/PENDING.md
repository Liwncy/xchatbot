# 学习草稿 / 待批 skill

> **依据**：被点名时携带的群聊历史，或 `xbot_chat_history` 查到的记录。没依据别写。  
> **转交口令**：你自己想清楚后可直接写 `skills/lazy/ROUTES.md`，不必等批准；没想清楚可先放这里。  
> **具体 skill / 真能力**：必须李芈仙批准后才能固化或真调用。

## 条目格式

```markdown
### <短标题>
- 类型：delegate | skill | capability
- 群：<群名或 roomId@chatroom | unknown>
- 摘要：<一句话>
- 触发：<什么场景该想起这条>
- 动作草稿：<口令模板 / 接口要点 / skill 设想>
- 依据：<历史里谁→谁，做了啥；勿臆造>
- 状态：draft | awaiting_owner | rejected
```
