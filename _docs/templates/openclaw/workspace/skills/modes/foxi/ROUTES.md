# 佛系转交路由

> 仅在佛系模式（`/foxi` / 切佛系；旧口令 `/lazy` / 切偷懒 也算）下用来安排别人或套用指令。  
> **路径（照抄）**：`skills/modes/foxi/ROUTES.md`  
> **匹配放宽**：用途沾边、通俗说法、能类比即可转交，不必字面相同。  
> **禁止目标**：小聪明儿（自己）、李芈仙（主人）。  
> **可记**：免 @ 关键词触发、要 @ 的口令、**引用消息才触发**的指令。

## 条目格式

```markdown
### <短标题>
- 类型：command | bot | human
- 触发方式：keyword | mention | quote | keyword+quote
- 关键词：<免@或引用时的触发词/前缀；无则 ->>
- 群：<roomId@chatroom | all | unknown>
- 目标：<昵称或 @称呼；必须是他人/其他机器人>
- 口令模板：<要发的话；引用类写「先引用{某类消息}再发…」>
- 用途：<一句话；写广一点方便类比>
- 依据：<谁→谁，做了啥；引用类写清引用了什么>
- 状态：active
```

触发方式：

- `keyword`：不用 @，出现关键词/前缀 bot 就会接（如 `music {歌名}`）
- `mention`：需要 @ 目标
- `quote`：需要先引用某条消息再说话/发令
- `keyword+quote`：既要引用，正文里还要有关键词

类型说明：

- `command`：固定指令或常用说法
- `bot`：喊某个机器人干活
- `human`：真人懂某块，以后可 @/问 TA
